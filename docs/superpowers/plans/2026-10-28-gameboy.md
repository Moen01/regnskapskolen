# Paragrafjakten på Game Boy (fase 1): implementasjonsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Paragrafjakten tegnes inne i en Game Boy-ramme: én logisk skjerm på 160 × 144 piksler, fire farger, pikselfont, dialogboks med skrivemaskin-tekst, kampskjerm der regelen er trekket og svaret er angrepet, tastatur (piler, Enter, Esc, Tab) og mus.

**Architecture:** All ny logikk som rene verdityper i `RegnskapKit`: tekstbryting og sider, artsnavn, sprite-generering, korte lovnavn fra `Innhold/lover.json`, kampreplikker, svarpanel-modellene (markør, skrivefelt, bilagslinjer) og kampflyten (fasene i et møte) med `GameKey` som inndata. Appen får et tynt skall under `UI/Game/GameBoy/`: `GBScreen` (skalering, palett, fokus, taster) og småkontroller som tegner modellene; skjermene for kart, region, møte, oppsummering og samling erstatter dagens views. `AppStore+Adventure` er uendret.

**Tech Stack:** Swift 6, SwiftUI (macOS 15), SwiftPM, XCTest. Én ny ressurs: fonten «Press Start 2P» (OFL). Ingen pakkeavhengigheter, ingen SpriteKit, ingen lyd.

**Spec:** `docs/superpowers/specs/2026-10-28-gameboy-design.md`

## Global Constraints

- Kit importerer aldri SwiftUI/AppKit. `GameKey`, panelene og kampflyten er verdityper uten `Date()`.
- Logisk skjerm 160 × 144 px; dialogboksen har 3 linjer à 18 tegn; svarpanelet er 152 × 90 px med tittel + 6 rader à 12 px; listerader avkortes til 17 tegn med `…`. Skala er et heltall 3–5; under 3 vises «Gjør vinduet større.».
- Palett (DMG): `#0f380f` mørkest, `#306230`, `#8bac0f`, `#9bbc0f` lysest. Fonten «Press Start 2P», 8 px per tegn ganger skalaen; fallback systemets monospace fet.
- Taster: ↑↓←→, Enter = A, Esc = B, Tab = bla dialogboksen, Delete = slett tegn/linje; alt som kan velges, kan klikkes.
- Minus i spilltekst er ASCII `-` (fonten mangler U+2212).
- Norsk bokmål i alt brukeren leser; kode, kommentarer og commit-meldinger på engelsk.
- Ingen død kode: `MapView`, `RegionView`, `EncounterView`, `RunSummaryView`, `CollectionView` slettes når erstatningen er inne.
- Commit etter hver oppgave med trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. `swift test` grønn etter hver oppgave.

- [ ] **Step 3: Implement `TextWrap`**

            }
        } }
    }

- [ ] **Step 3: Implement `PixelSprite`**

Half-width grid (`width / 2` columns), seeded `SplitMix64` from FNV-1a of the seed. Fill rule: a cell is body when the generator draws below a probability that is higher in the middle rows and columns (`0.75` at the centre falling to `0.3` at the rim), then keep only the largest 4-connected component so the creature is one blob; mirror; mark as outline every transparent cell 4-adjacent to body (inside the grid; body cells on the grid edge become outline); put two eyes at the body cells nearest to (`width/2 - 2`, `height/3`) and its mirror. `player` is a literal 16 × 16 string array (hair/shirt as 1, skin as 2, glasses as 3) converted once.
